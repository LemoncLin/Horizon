## [AI Coding Agents Installing Untrusted Code on Corporate Networks](https://www.schneier.com/blog/archives/2026/09/ai-coding-agents-are-installing-unknown-untrusted-code-on-corporate-networks.html) ⭐️ 8.0/10

Security researchers discovered that AI coding agents, including Claude, Codex, and Hermes, are downloading untrusted code packages from unregistered domains on corporate networks, with some Fortune 500 companies contacting malicious servers within an hour of deployment. This reveals a critical supply-chain security vulnerability where AI agents autonomously execute code from unverified sources, potentially exposing corporate networks to malware and data exfiltration. The researchers tested 6,214 live domains across defense contractors, Fortune 500, and Big Tech companies, finding that 120 unregistered domains hosted code packages that triggered phone-home behavior when processed by AI agents.

rss · Schneier on Security · Sep 4, 10:35

**Background**: llms.txt is a metadata file that AI coding agents read to understand a website's structure and locate code packages. When these agents encounter references to unregistered domains, they may automatically download and execute code from those sources, creating a supply-chain attack vector.

**Tags**: `#AI Security`, `#Corporate Security`, `#Malware`, `#AI Agents`, `#Supply Chain Security`
