## [Sched-ext Finalizes Sub-Scheduler Hierarchies and Proxy Execution Support](https://lwn.net/Articles/1082717/) ⭐️ 8.0/10

The Linux kernel's sched_ext subsystem is finalizing support for hierarchical sub-schedulers and resolving a long-standing incompatibility with proxy execution. This update enables BPF-based custom schedulers to manage nested scheduling queues and properly handle task migration across CPUs. These architectural improvements significantly enhance the flexibility and performance of Linux's extensible scheduling framework, allowing developers to implement complex, multi-level scheduling policies without modifying core kernel code. It directly benefits cloud computing, real-time systems, and specialized workloads that require fine-grained CPU resource management. The changes introduce an enqueue() hook specifically designed for sub-schedulers, facilitating tighter control over queuing latency and priority inheritance. Additionally, the proxy execution patch resolves issues where blocked donor tasks were incorrectly pulled off runqueues during BPF-directed migrations.

rss · LWN.net · Jul 16, 14:00

**Background**: Linux's traditional scheduler has historically been monolithic, making it difficult to experiment with new scheduling algorithms without risking system stability. The sched_ext framework addresses this by allowing developers to write custom scheduling policies as eBPF programs that run in safe, sandboxed environments. Proxy execution is a technique used to solve priority inversion problems by temporarily running a lower-priority task on behalf of a higher-priority one, while sub-schedulers enable hierarchical resource partitioning for complex multi-tenant environments.

## [ExTernD Achieves Near-Arbitrary Accuracy in Ternary LLM Post-Training Quantization](https://www.reddit.com/r/MachineLearning/comments/1uy2zb3/externd_expandedrank_ternary_decomposition/) ⭐️ 8.0/10

Researchers introduced ExTernD, a novel post-training quantization method that decomposes LLM weight matrices into two ternary matrices and a diagonal scaling matrix. This expanded-rank approach allows the model to achieve accuracy comparable to higher-bit quantizations while maintaining minimal VRAM overhead. This breakthrough addresses a major bottleneck in deploying efficient AI by proving that ternary quantization does not have to sacrifice accuracy. It paves the way for highly optimized, low-resource LLM inference without relying on computationally expensive higher-bit formats. The method overcomes traditional fixed-size ternary limits by making the inner decomposition rank arbitrarily adjustable, trading a slight increase in VRAM for massive gains in computational efficiency through ternary arithmetic. It specifically utilizes a greedy decomposition algorithm to approximate original weights with high fidelity.
