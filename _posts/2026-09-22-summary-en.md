## [vLLM v0.30.0 Released with Fast Start and DeepSeek-V4.1-Flash Support](https://github.com/vllm-project/vllm/releases/tag/v0.30.0) ⭐️ 8.0/10

vLLM v0.30.0 is a major release featuring 762 commits from 315 contributors, introducing Fast Start weight caching, DeepSeek-V4.1-Flash with MXFP8 KV storage on SM100, and support for multiple new models. This release significantly advances LLM inference performance and flexibility, with Fast Start reducing restart latency and new model support expanding vLLM's ecosystem. Fast Start uses a persistent per-GPU weight-cache daemon with CUDA IPC, while DeepSeek-V4.1-Flash leverages FlashMLA V4.1 on SM100 with MXFP8 KV storage.

github · khluu · Sep 22, 05:20

**Background**: vLLM is an open-source LLM inference engine known for high throughput and efficient GPU utilization. It supports various quantization methods and model architectures. This release adds performance optimizations and new model backends.
