## [惊艳渗流证明解决数十年相变难题](https://www.quantamagazine.org/stunning-percolation-proof-solves-decades-old-puzzle-about-phase-transitions-20260831/) ⭐️ 9.0/10

数学家已证明，一大类网络在越过临界阈值后会发生突然的行为转变，从而解决了渗流理论中关于相变的长期悬而未决的难题。 这一突破连接了数学与统计物理，为数十年来在各类网络、材料科学和复杂系统中通过经验观察到的现象提供了严格的理论确认。 该证明适用于一大类网络而非单一特定模型，这正是该结果尤为强大且可推广至不同类型随机系统的原因。

rss · Quanta Magazine · 8月31日 14:24

**背景**: 渗流理论研究随机系统中连通性如何形成，例如流体如何穿过多孔材料。临界阈值是系统突然从仅有少量孤立簇转变为形成贯穿整个系统的单一连通路径的点——即相变。这一概念对于理解从病毒在网络中的传播到复合材料导电性等各类现象至关重要。

## [谷歌从 Chrome 应用商店移除 MV2 扩展](https://webiterate.dev/google-removed-extensions-ublock-origin-108/) ⭐️ 8.0/10

谷歌已从 Chrome 应用商店移除 Manifest V2 扩展，包括流行的广告拦截器 uBlock Origin。此举是谷歌自 2022 年 1 月停止接受新的 MV2 扩展以来，逐步淘汰该平台的最新一步。 这一政策变化对依赖广告拦截器和隐私保护扩展的用户影响重大，因为 MV3 对内容拦截能力施加了更严格的限制。这也引发了关于谷歌对浏览器生态系统和互联网信息流单方面控制的更广泛担忧。 Manifest V3 用更有限的 declarativeNetRequest API 替换了原有的 blocking request API，限制了扩展可使用的规则数量，并阻止了实时内容过滤。Firefox 继续支持 MV2 和 MV3，目前没有淘汰计划。

hackernews · twapi · 8月31日 21:10 · [社区讨论](https://news.ycombinator.com/item?id=49514878)

**背景**: 浏览器扩展是小型软件程序，为网络浏览器增添广告拦截、隐私保护和生产力工具等额外功能。Manifest V2 是原始的扩展架构，允许扩展实时拦截和修改网络请求，使 uBlock Origin 等广告拦截器能够发挥全部功能。谷歌推出的 Manifest V3 代表了一种更受限的架构，旨在提高安全性和性能，但代价是扩展功能受到限制。

## [滑动窗口注意力在长上下文推理中超越线性注意力](https://www.reddit.com/r/MachineLearning/comments/1w3j1vw/slidingwindow_attention_beats_linear_on/) ⭐️ 8.0/10

一篇新的 arXiv 预印本论文声称，滑动窗口注意力（带 sink 机制）在 Needle-in-a-Haystack 和 BABILong 等长上下文推理基准测试中，性能比线性注意力变体高出 2 到 10 倍，且无需后训练。 这一发现挑战了当前行业将后训练计算资源投入线性注意力模型的趋势，表明更简单的滑动窗口注意力可能是长上下文推理更有效的方案，可能引导 LLM 架构领域的研发策略调整。 论文指出，线性注意力研究一直与不充分的基线进行比较，线性注意力变体可能需要从头训练或大量后训练才能匹配滑动窗口注意力在长上下文任务上的性能。

reddit · r/MachineLearning · /u/Justgototheeffinmoon · 8月31日 16:35

**背景**: Transformer 中的标准自注意力机制的计算和内存复杂度随序列长度呈二次方增长，使其难以处理长上下文。Mamba、RetNet 和 GLA 等线性注意力变体旨在将复杂度降低到线性时间，但往往在长上下文推理任务上牺牲性能。滑动窗口注意力通过允许每个 token 只关注固定窗口内的邻近 token 来解决这一问题，而 sink token 则关注所有位置以保持全局信息流动。
