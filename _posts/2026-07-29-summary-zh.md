## [微软 Secure Boot 存在长期漏洞](https://www.schneier.com/blog/archives/2026/07/long-lived-vulnerability-in-microsoft-secure-boot.html) ⭐️ 9.0/10

ESET 的研究人员发现，由于存在缺陷但仍被签名的 shim 固件镜像，微软的 Secure Boot 在其 14 年历史中的 13 年里都很容易被绕过。 这是 Windows 和 Linux 系统使用的基础安全技术的严重缺陷，破坏了整个计算生态系统中固件保护机制的完整性。 该漏洞源于微软在发现 shim 镜像存在漏洞后未能撤销公开可用的镜像，使得即使是新手黑客也能使用简单技术绕过 Secure Boot 保护。

rss · Schneier on Security · 7月29日 11:01

**背景**: Secure Boot 是 UEFI 的一项功能，旨在防止未经授权的系统启动代码运行。Shim 是一个小型 EFI 应用，通过根据嵌入式证书验证引导加载程序来扩展 Secure Boot 对 Linux 的支持。

## [自旋穿梭硅量子比特器件实现四权重奇偶校验](https://www.nature.com/articles/s41586-026-10766-3) ⭐️ 9.0/10

这一突破解决了可扩展量子纠错中的关键挑战，证明自旋穿梭架构可以在半导体量子处理器中实现更高权重的奇偶校验，这对于容错量子计算至关重要。 实验使用带有自旋穿梭总线的硅量子比特器件来运输量子比特并对多达四个量子比特执行 X 型奇偶校验，形成 GHZ 态以进行错误检测。这项工作展示了将自旋穿梭集成到半导体量子处理器中以实现可扩展 QEC 的可行性。
