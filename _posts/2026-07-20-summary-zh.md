## [天文学家已确认岩石系外行星 LHS 1140b 拥有大气层](https://hackaday.com/2026/07/20/earth-like-lhs-1140b-may-feature-the-first-atmosphere-found-on-exoplanet/) ⭐️ 9.0/10

研究人员已在距离地球 49 光年的红矮星宜居带内确认了岩石超级地球 LHS 1140b 的大气层。此次通过观测逃逸氦元素发现的迹象，标志着人类首次在类似岩石的宜居带系外行星上确认大气存在。 这一发现是天体生物学和搜寻地外生命进程中的重要里程碑，因为此前对系外行星大气的探测主要集中在气态巨行星或极热天体上。它为未来利用望远镜研究生物特征信号和评估行星宜居性铺平了道路。 该行星质量约为地球的 5.6 倍，半径比地球大约 70%，模型显示它可能是一颗含水量高达 19%的海洋世界。科学家主要利用其凌星时的观测数据，通过探测逃逸的氦元素来确认大气层的存在。

rss · Hackaday · 7月20日 11:00

**背景**: 系外行星是指围绕太阳以外恒星运行的行星，天文学家通常利用凌星法探测其大气层，即行星经过恒星前方时，星光会穿过其高层大气。此前的系外行星大气探测主要集中在热木星或热海王星上，因为它们的受热膨胀大气更容易通过光谱分析。相比之下，位于宜居带内的岩石行星由于体积较小且大气信号微弱，一直难以进行详细研究。

**背景**: arXiv 是分享学术论文的重要平台，研究人员通常在此发布正式出版前的稿件。AI 写作检测器通过分析文本模式来评估内容是否由大语言模型生成，尽管这些工具仍不完善且容易产生误报。该研究在 ChatGPT 发布前后的五年时间窗口内应用这些检测器，以追踪不同学科在 AI 辅助写作方面的差异。

## [美军应用近三分之二嵌入中俄代码](https://www.wired.com/story/apps-marketed-to-us-troops-are-shipping-chinese-and-russian-code/) ⭐️ 8.0/10

普渡大学研究人员发现，在面向美军推广的 220 余款应用中，近三分之二嵌入了来自中国或俄罗斯的第三方代码，其中包括华为 SDK。尽管目前尚未确认数据外泄，但这些 SDK 支持远程更新，存在潜伏代码被激活的风险。 这一发现揭示了美军生态系统中的关键供应链安全漏洞，敌对国家可能利用嵌入代码访问敏感用户数据或监视相关人员。该结果加剧了关于国防相关应用依赖外国技术组件所引发的国家安全争议。 研究指出目前未观察到数据流向华为服务器，但强调这些 SDK 可接收远程更新，从而可能激活潜伏代码。针对 103 名军人关联人员的调查显示，76% 至 83% 的人对敌对国家代码出现在应用中感到极度不安。

telegram · zaihuapd · 7月20日 13:42

## [未维护的 Fastjson 1.x 被曝无需 Gadget 的高危 RCE 漏洞](https://x.com/k_firsov/status/2078872293745570032) ⭐️ 8.0/10

安全研究人员 Kirill Firsov 披露，Fastjson 1.2.68 至 1.2.83 版本存在高危远程代码执行漏洞，该漏洞在 JDK 8、17 和 21 上均可利用，且无需开启 autoTypeSupport 或依赖 classpath gadget。由于 Fastjson 1.x 已于 2024 年 10 月停止维护，官方极大概率不会推送补丁，因此迁移至 Fastjson2 成为唯一的修复建议。 对于依赖旧版 Fastjson 的 Java 开发者而言，这一无 Gadget 的新型攻击向量绕过了传统的反序列化防御机制，且影响运行受支持 JDK 版本的广泛部署环境，因此至关重要。由于该库已停止维护，组织必须立即采取行动以防止潜在的远程代码执行攻击，而不能等待上游修复。 该漏洞无需开启 autoTypeSupport，也不依赖 classpath 中的特定 Gadget，相比以往的 Fastjson 缺陷降低了利用门槛。建议用户立即审查相关依赖，并尽快升级至 Fastjson2，或通过启动参数及配置文件启用 SafeMode。

telegram · zaihuapd · 7月20日 14:32

**背景**: Fastjson 是一个广泛用于 Java 应用程序中解析和生成 JSON 数据的库，但其旧的 1.x 分支已于 2024 年 10 月停止维护。在 Java 安全领域，Gadget 链是指应用程序类路径中现存的对象序列，这些对象可在反序列化过程中被串联起来以执行任意命令。以往的 Fastjson 漏洞通常依赖于开启 AutoType 或寻找特定的 Gadget，但此次新漏洞表明存在一种无需这些前提条件的危险利用途径。
